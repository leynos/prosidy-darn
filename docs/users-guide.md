# Prosidy Darn users' guide

Prosidy Darn remains in the design and scaffold stage. Its planned segmentation
library, command-line interface, and output adapters are not yet implemented;
there are no supported user-facing workflows yet.

The proposed API and command contracts are recorded in the
[technical design](prosidy-darn-technical-design.md). This page contains no
code-fence examples until supported workflows exist. When examples are added,
each will have a stable `tested-example` identifier and the test suite will
load and exercise it from this published guide, as required by the
[documentation style guide](documentation-style-guide.md).
